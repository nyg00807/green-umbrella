## 📌 개요
본 프로젝트는 실제 웹사이트를 분석하고 구현 능력을 향상시키기 위해 진행한 클론 코딩 프로젝트입니다.<br>
원본 사이트의 레이아웃 구조와 사용자 인터페이스를 참고하여 HTML, CSS, JavaScript를 활용해 직접 구현하였습니다.

<br>

## 💬 회고
실제 운영 중인 웹사이트를 클론 코딩하며 레이아웃 구성과 인터랙션 구현 과정을 경험할 수 있었습니다.<br>
단순히 화면을 따라 만드는 것에서 끝나지 않고 원본 사이트의 구조와 동작 방식을 분석하며 퍼블리싱 역량을 향상시킬 수 있었습니다.

구현 과정에서는 원본 사이트의 복잡한 레이아웃 구조와 동적인 기능을 재현하는 데 어려움이 있었지만,<br>
HTML 구조를 다시 설계하고 CSS 레이아웃 및 JavaScript 로직을 반복적으로 수정하며 문제를 해결하였습니다.

이번 프로젝트를 통해 실제 서비스의 구조를 분석하고 구현하는 과정을 경험할 수 있었으며, 퍼블리싱 과정 전반에 대한 이해도를 높일 수 있었습니다.
